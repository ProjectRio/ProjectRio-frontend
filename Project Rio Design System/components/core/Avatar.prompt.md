Round identity chip for players in nav, ladders, and headers.

```jsx
<Avatar name="DingerCity" />               // initials "DI" on Rio red
<Avatar name="Mario" src="assets/characters/Mario.png" size={48} />
```

Defaults to two-letter initials on a solid rio-500 disc; pass `src` for a character sprite (rendered pixelated). Used at 36px in the nav, larger on profile headers.
