Tiny uppercase pill for labeling modes, tags, and statuses.

```jsx
<Badge color="red">Big Balls Brawl</Badge>
<Badge color="gold">Official</Badge>
<Badge color="gray">Unofficial</Badge>
<Badge color="green">+18 ELO</Badge>
```

Four semantic colors, each a translucent tint of its base over a matching border. Use `red` for game modes, `gold` for highlights, `gray` for neutral metadata, `green` for positive deltas.
