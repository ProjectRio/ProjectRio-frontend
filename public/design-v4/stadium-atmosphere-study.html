Specimen 03

The chemistry triangle

Real data

The best data visual the game has to offer, and it has never been drawn. The table is perfectly symmetric — zero of 1431 pairs disagree — so half of a square grid would be redundant and it renders as a triangle. Three bands, not a ramp, because 90 and 20 are hard lines the game itself draws. Hover or tap any cell.

Hover a cell to read the pair.
Buddy · 90+ · 101 pairs Neutral · 20–89 Anti · under 20 · 53 pairs
Why this works as a centrepiece. With 101 bright pairs and 53 hostile ones against a mean of 59.9, it has genuine structure rather than noise — the clusters are visible without a legend. And because the thresholds are the game's own, it is not a generic heatmap: there are exactly three states, which is the same rule the chemistry badge follows.

Specimen 07

Challenges in the game's voice

Verbatim copy

All twelve scout banners, recovered this session. A complete challenge vocabulary already written — imperative, specific, never congratulatory. This is what Rio's own daily or seasonal challenges should sound like, and the banner treatment is the loud register doing its one job.

Verbatim from entry 2513, 231–450 × 44 C4, frame-mapped through scoutMissionBannerFrames[] and layout element 0x65. Note that SMACK A HIT!, quoted in an earlier pass, turned out to be the explainer's example rather than a texture.

Refinement, not a new direction.

  • Same type family. Lilita stays expressive; condensed labels and monospace values do the quieter work. Tighter heading rhythm, more readable secondary text.
  • More legible chrome. A slightly warmer neutral rim and clearer green staging help the translucent surfaces read. No colored card rails or new decorative border system.
  • Use the original shapes. The chemistry composites and team emblems provide the distinctive outlines. They replace approximations, not the underlying design language.
  • Keep the game’s proportions. Compact continuous gauges, small portraits, a calm selection bar, and disciplined spacing. No full-page character collage or new product features.

V4 is a design proposal. Original research prose and specimen interactions are retained from v3; they are not newly verified findings. Chemistry composites: v3/evidence. Emblems and portraits: existing frontend assets. Motion remains a web approximation.

What is real and what is not. Concepts 2 and 3 run on the actual roster file — 54 CharacterStats rows 0xA0 apart, chemistry at +0x3B, validated against every published signature (diagonal all 50, zero asymmetric pairs, 101 buddies, 53 anti, mean 59.9). Concept 7 is verbatim game copy. Concept 1's timings are exact and its easing curve is a stand-in. Concept 5's figures and growth titles are placeholders. Concept 4 arranges real HUD elements into a layout the game never uses.

Still not shipped. Nothing here is in the repository — these are concepts to judge, not code to merge. The roster data is embedded in this page as JSON; wiring it to a real endpoint is a separate job.
